# 个人配置备份与迁移

入口：设置中的“版本与手动升级” → “个人配置与脚本迁移”。

## 导出

1. 保存正在编辑的脚本，停止任务、录制和盒子重连。
2. 点击“导出 ZIP…”，选择保存位置。
3. 页面显示导出成功后，将这个 `.zip` 文件保存到新版本目录之外。

ZIP 压缩与解压已集成在小助手中，使用现有 .NET 运行时的标准 ZIP 能力，无需安装、下载或选择任何外部压缩工具。中文文件名采用 UTF-8 编码。

备份包含已保存的 `config/**/*.json`、`recordings/**/*.json`（包括隐藏的绑定索引、默认脚本登记及恢复草稿）、`appsettings.json` 和资源目录中的 `mfa_layout.json`。自定义配置目录使用宿主实际生效的目录。未保存的编辑器内容、游戏账号文件、助手程序、任务资源、日志和旧程序备份不会打包。单文件上限 64 MB，总数据上限 512 MB，最多 10000 个文件。

## 导入

1. 打开新助手，在同一页面点击“导入 ZIP…”。
2. 检查来源资源版本、文件数量及同名覆盖数量，点击“确认导入，下次启动生效”。
3. 正常关闭同一目录的所有助手，再打开助手。恢复会在读取个人配置之前完成。

选择文件和预览不会覆盖当前配置。确认后也可以点击“取消待导入备份”。仅导入你信任的、由助手导出的备份；仅支持带有助手备份清单的 ZIP，不支持其它格式改后缀、分卷或加密压缩包。

导入覆盖备份内的同名文件，保留不在备份内的其它文件；原文件先保存到 `.personal-transfer/backup-*`。备份中的程序文件、越界路径、链接、重复路径、超限文件、校验不符及不支持的清单版本会被拒绝。

如果恢复时写入失败，助手恢复原文件；如果进程在恢复中被终止，下次启动会先按日志回滚。失败的待导入内容保留在 `.personal-transfer/rejected-*`，不会无限自动重试。结果和原配置备份位置显示在版本页面。迁移到新电脑后，请重新核对盒子路径、窗口与存档设置。

## 离线回归

- `frontend/tests/PersonalTransfer`：无需额外参数或压缩工具，验证真实 ZIP 往返、覆盖备份、异常回滚、进程中断恢复、路径和校验限制。
- `frontend/tests/PersonalTransferUi`：通过 `MfaBuildDirectory` 指定实际编译前端，参数为离屏图片输出目录。使用 Avalonia Headless 检查导出、导入预览、确认、取消及窄窗口布局，不打开真实窗口。

本功能使用 `System.IO.Compression` 逐项读取 ZIP 条目，在文件清单和 SHA-256 校验通过后自行写入，不使用整包自动解压到目标目录。

旧版 RAR 备份不直接导入。若需继续使用旧备份，可先解压，再把根目录的 `manifest.json`、配置和录制目录按原结构重新压缩为 ZIP；不要只改扩展名。已经在旧版本中确认、暂存好的待导入内容保持兼容，不需要重新选择。
