# 2.5.4 更新说明

- 恢复脚本分组、页面引导、日志清理和可关闭的 64 MB 日志滚动。升级 2.5.3 请使用完整客户端，保留个人配置、布局、录制和绑定。
- 保留自动航海。航海使用随包提供的 Python 和模型依赖，向当前绑定的盒子窗口发送输入；点击停止可以结束航海，子进程报错会反馈给任务队列。
- 修复竞技场入口与结算识别，补充失败画面的识别。通用进关复用当前画面，点击未生效时可在原入口重试。
- 回放结束后点击副本设置按钮中心，等待菜单出现后再返回地图。两次点击仍未打开菜单时给出具体原因，本轮不计次。
- 游戏管理支持账号名、角色名独立留空。重启选档复用刚核对的存档位置，减少页面切换时二次识别失败。窗口比例异常、界面未知等错误会提示处置方式。
- 收紧复活面板取消按钮的识别，避免按钮被遮挡时误点。
