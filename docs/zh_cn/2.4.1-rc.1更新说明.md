# 2.4.1-rc.1：挂机与重启恢复测试版

这是待实机验收的预发布版本。已完成源码检查、无前台的控件检查和内存控制器/Agent 通道回归；未完成真实游戏重启、长时间挂机和图形安装器验收。

## 挂机模式

11 个有战斗录制与明确结算边界的任务新增“挂机模式”勾选项，默认关闭。开启后无限刷取、无限重试已确认的战败，直到手动停止。次数、失败重试及重复选项显示为禁用，但原值保留，关闭挂机后恢复使用。

开启“任务失败后自动重启”时，挂机的战败重试会经过核验进程、重新绑定窗口、登录和存档确认。验证码、未知界面、空存档、角色不匹配、脚本改写等不会被当作可无限重试的战败；窗口丢失、白屏等恢复预算和内存重启保护继续有效。替代整个任务的录制缺少结算边界，不能开启挂机模式。

## 重启恢复

恢复链路为：核验新进程与唯一窗口 → 刷新连接目标 → 检查客户区 → 历史账号 → 造梦西游4 → 等待加载 → 开始游戏 → 核对已有存档及角色 → 地图 → 原任务同轮导航。

- 先刷新已核验的新窗口，即使尺寸检查失败也不会继续显示旧的失效目标。
- 用 Maa 720p 归一化后的画面尺寸判断一致性，允许保持比例的 AIR/DPI 缩放。比例变化仍需有界调整，无法确认时不发送游戏输入。
- 存档选择扩展到 1～8。角色 OCR 允许“角色名 Lv.等级”同一行，仍要求配置的角色名完整匹配；空存档和不同角色不会被点击。
- 加载画面只等待，不点击；恢复日志记录阶段与客户区尺寸。
- 继续包含免费复活提示的限定区域 OCR 备用识别及取消按钮布局校验。

## 上游 2.4.0 图鉴缺失核查

核查对象是 [Inkyu-Zero/MAAZMXY4 v2.4.0](https://github.com/Inkyu-Zero/MAAZMXY4/releases/tag/v2.4.0) 实际发布的 `MAAZMXY4.v2.4.0.exe`，SHA-256 为 `1e81f0b70545e9f2480a31a1cd12debfe8408010b0163494e054ff62b447d0bc`，与该 Release 的校验清单相符。

包内 `interface.json` 和安装记录都标为 2.4.0，但 `script-studio-build.json` 只记录早期 01～17 号补丁；包内 `libs/MFAAvalonia.Core.dll` 有脚本工作台类型，却没有 `GameDatabaseView`、`GameDatabaseViewModel`、`GameManagementView` 类型。源码和归档中的图鉴数据并不能给旧前端增加入口。此问题是新资源与旧前端混装，资源版本号不足以证明客户端功能齐全。

本版构建记录加入前端源码及二进制哈希，完整包构建必须核对上游提交、补丁集合、源码与程序集，拒绝类似旧前端混装。公共示例录制只按已审阅清单逐项校验后打包；个人录制目录仍排除。

## 手测重点

1. 勾选挂机后，次数和重试项禁用；取消勾选恢复原值。
2. 战败后取消复活并继续同轮重试，手动停止不再导航或重启。
3. 启用失败重启后，窗口列表更新到新 HWND，依次完成登录、加载、存档核对和原任务导航。
4. 图鉴侧栏存在，能读取离线数据。

本版本没有修改按键回放的时间调度，不能据此认定此前观察到的按键时序偏差已解决。
