# 2.5.2-rc.1 候选说明

这是基于正式 2.5.1 的完整客户端候选，使用 EXE 或 ZIP 手动安装，通用自动更新保持关闭。候选在 fork 发布，完整包验收记录和实际下载摘要随 Release 提供；不替代上游正式版本。

## 功能与改进

- 完整包包含固定版本的造梦盒子及 AIR；脚本库支持单层分组、拖动整理和整组删除，页面说明可重看或请求下次启动重置。
- 主线覆盖 65 关，保留主动添加规则；补齐竞技场导航和结果返回，改进游戏管理常用操作及高级设置布局。
- 省份身份模板短路、同帧守卫结果复用、停止查询节流，减少识别与通信开销。倍速切换只发送两次按键；只读执行计划服务及时退出，原生历史在结果消费后的空闲边界释放。
- 设置提供先预览后确认的手动日志清空，以及默认开启、共享并持久保存的日志滚动开关。关闭后仍正常写入，仍可手动清空。
- `debug`、`logs` 中可管理日志共用 64 MiB 目标，前端和相关 Python 流约 4 MiB 分块，超限优先回收最旧的已关闭块；活动 Maa 日志可能暂时超限。
- 修复 ROI 优化对偏移复活面板的回归：恢复短句原识别范围，保留确认框及其它优化。

## 验证与局限

源码由 Windows CI 执行逻辑回归、前端构建、Headless 界面、内存控制器及 Agent IPC 验证；新增日志与历史清理专项。复活偏移回归保留完整样本和断言。完整包另按 EXE、ZIP、升级保留及包内依赖验收，最终结果见候选发布页。

倍速状态表示操作已派发，不表示识别确认实际倍率。省份节点从 `TemplateMatch` 改为 `Or`，第三方旧模板覆盖须适配。离线测量只证明对应样本；真实游戏中的角色、窗口、快捷键和全部任务组合不属于完整包安装验收的自动保证。Maa 原生库未修改，不强制截断正在使用的日志，也不在活动原生任务中清空历史。

升级前保留个人配置和录制备份，使用[个人配置 ZIP 迁移](个人配置备份与迁移.md)。更多实现与验证细节见[性能与日志优化说明](性能与日志优化说明.md)和[脚本工具使用说明](脚本工具-使用说明.md)。
