# 2.5.5 更新说明

## 新增任务：福果来

「师兄，果来」限时活动。

- 自动从当前界面走回大地图，展开活动菜单，点进福果来面板
- 面板上「进入副本」是灰的就直接输出「本日福果来活动已完成」并收工，不会误点
- 副本内自动走位接果子，按需释放 Y / U / O 技能
- 左上角出现守护兽预警就停摇，泡泡消失后恢复
- 一局结束读结算面板的「获得积分」：≥600 才领奖，不够就返回地图再跑一轮

## 新增：生存大冒险自动导航

以前必须先手动把游戏停在答题界面，现在任务自己走：

- 大地图 → 展开活动菜单 → 点生存大冒险 → 点「开始冒险 / 继续冒险」
- **任意状态都能启动**：停在大地图、菜单已展开、七天卡片页、甚至已经在答题中，任务都能识别出当前在哪一步并接着往下走
- 中途接手时按顶部进度条的金色圆点数出真实题号，不会算错
- 本日只能「重新冒险」（要花点券）时，输出提示并收工，不消耗点券
- 一局结束后自动点「返回地图」回导航

## 新增：航海寻宝自动导航

- 自动走回大地图、展开菜单、点进航海寻宝、点「起航」
- 面板上是「领取奖励」而不是「起航」时，先领奖再看剩余次数
- 新增「执行日」选项：只在指定的星期几运行
- 新增「完成方式」选项：只完成一轮 / 清空奖励次数

## 体验改进

- 导航会先判断当前停在哪个界面再决定怎么走，不再要求先把游戏退回大地图
- 导航过程中不会再出现卡在原地、反复点同一处的情况
- 福果来图标带金色高亮光晕时也能正确点中
- 各任务的失败路径都会回到入口重试，不会中途停住

## 已修复

- 活动菜单已经展开时，导航不再重复点菜单或误点底部按钮
- 结算面板的「获得积分」能正确读取，达标判断准确
- 面板右上角的关闭按钮不会再漏识别
- 启动器与前端同步到最新版本
