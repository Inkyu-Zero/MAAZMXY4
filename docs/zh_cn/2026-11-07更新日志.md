# v2.4.6 更新日志

本次更新包含主线刷关、可选倍速、后台点击及脚本工具改进，对应 [PR #11](https://github.com/Inkyu-Zero/MAAZMXY4/pull/11)。此前暂缓的 PR #9 功能随本次恢复。

- **新增 62 个普通主线关卡任务**：覆盖四洲及幽冥血海，可在任务列表按地图分组添加。为每个关卡绑定自己的战斗录制后，使用公共导航、进关重试、战败处理及返回确认流程；不会自动填满已有任务列表或替换旧绑定。
- **新增盒子与脚本二倍速选项**：确认盒子已切换二倍速后，按对应倍率播放录制；连续轮次复用倍率，任务结束、失败或停止时尝试恢复一倍速并确认。录制文件及保存时长不变；默认一倍速不主动发送倍速按键。
- **改进悬赏任务识别**：四个悬赏任务使用右侧描述段落确认身份，同时保留页签、已接受状态及“前往副本”按钮检查。
- **修复 AIR 后台点击的目标切换问题**：针对孤魂岭按下、抬起命中不同子对象而无法生成点击事件的原因，在导航及回放期间过滤目标窗口的额外鼠标离开通知。无需把真实鼠标放在入口或抢占前台，操作结束、停止或异常后解除保护。
- **统一入口点击规则**：一倍速按住 100ms，确认二倍速后按住 50ms；地图主线入口采用双击，完成后后台移开悬停。点击参数本身不能替代鼠标离开保护，进关仍以场景识别结果为准。
- **完善窗口与进关恢复**：保留入口未响应时的新帧核验与重试，改进播放前窗口适配及尺寸取整容差，避免使用操作前的旧识别框继续点击。
- **改进脚本编辑与百科交互**：延续本版时间轴复制粘贴及百科交互改进，方便整理录制操作和查看游戏资料。
- **改善 Windows 文件系统兼容性**：脚本新建、复制、默认模板入库、首次绑定及迁移不再依赖硬链接，可用于 FAT32、exFAT 等文件系统；仍保留同名冲突、修订检查与用户数据保护。
- **补齐原生模块交付与验证**：完整安装包包含后台鼠标保护 DLL 及构建校验记录。模块缺失或目标窗口不可用时，在输入前报错；新增跨进程过滤、释放、异常退出和队列处理回归。

升级前请关闭小助手并导出个人配置备份。请使用完整 EXE 或 ZIP，避免只替换 Agent 文件而遗漏原生模块；配置、录制和绑定按现有迁移规则保留。继续采用完整客户端手动安装，不启用自动更新。使用二倍速前需关闭盒子高帧率，该功能不适用于联机副本；任务期间不要手动切换倍率。

本次已完成隔离 AIR、原生消息、Agent IPC 和安装包依赖检查；EXE 实际隔离安装与 ZIP 检查均通过。真实孤魂岭连续进关效果仍待用户复测，隔离环境中的成功次数不代表所有盒子、角色和 DPI 组合均已验证。此修复也不代表已解决技能冷却、动作状态等原因造成的技能未释放问题。
