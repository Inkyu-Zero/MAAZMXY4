# 脚本工具：录制、脚本库与时间轴编辑

“脚本工具”是 MFAAvalonia 内的原生页面，沿用现有侧栏和主题，包含两个子标签：

- **脚本库与录制**：管理脚本文件，在每行设置任务绑定，选择游戏窗口并录制。
- **时间轴编辑**：直接从脚本库选择文件，调整键鼠操作、标记和时间，并保存。

已有 `recordings/*.json` 可直接打开。也支持导入 ZaoMengScript 的 `zaomeng.macro` v1 录制；导入时转换时间单位和720基准坐标，保存后生成本项目格式，不修改源文件。

Windows 下新建脚本、默认脚本入库、复制、首次绑定及迁移不再依赖硬链接，可用于 FAT32、exFAT 等文件系统。文件先在同目录完整写入并刷新，再通过拒绝覆盖同名目标的重命名发布；编辑已有文件仍保留修订校验和替换流程，保存失败时保留未保存内容。

四洲及幽冥血海的 62 个普通主线关卡可从任务列表的“＋”按地图分组添加，不会自动填满现有任务列表。添加后在脚本库绑定该关卡的战斗录制，再设置完成轮数或挂机模式。旧任务与旧绑定继续保留；新增的“主线（关卡名）”任务使用独立绑定，不自动套用同名旧任务的录制。

主线任务复用自动导航、进关重试、播放前窗口适配、战败处理和返回地图确认。地图上仅匹配当前目标的局部入口，进关后复用无双按钮确认已进入战斗；血海入口缺失时复用左右端点拖动。需要已解锁的普通关卡；首次剧情、未解锁关卡、未知弹窗或缺少绑定时，不会盲点或自动跳过。任务不会生成战斗脚本，具体战斗由绑定录制完成。普陀山脚与九龙宝殿共用开场背景，通过各自入口识别加通用战斗确认建立进关上下文。

开发版新增任务列表中的“通用脚本播放”。在脚本库为它绑定一份已保存录制，选择播放次数，或勾选“持续播放”直到手动停止；持续播放会禁用次数输入并保留原值。每完整播放一次计为一次完成，不代表游戏通关。回放期间不截图、不识别、不导航，不执行战败重试或游戏管理的自动重启，实时预览暂停；默认 1 倍全程不截图，选择 2 倍时仅在开启及恢复倍速阶段核验盒子提示。请自行准备起始界面，并在录制中安排等待、退关和循环衔接。纯播放使用 SendMessage / PostMessage 后台输入；其它输入模式会提示调整，不会静默切换。

打开、连接和录制均保留当前窗口大小，不锁定尺寸；录制按实际客户区保存短边720的坐标基准。只在执行已绑定脚本的准备阶段适配一次：当前比例已符合脚本时保留大小，否则在当前客户区范围内调整为脚本比例。普通任务在进关识别前完成这次适配，防止比例异常导致任务到不了回放步骤；导航期间不锁定尺寸。纯脚本播放在发送脚本输入前适配，不改写录制文件。

播放期间限制拖拽缩放及最大化，仍可移动窗口；输入前只检查尺寸与窗口身份，不再次调窗。允许8个物理像素的取整误差，并沿用720基准下8像素的布局容差。外部强制改变尺寸或窗口身份时停止输入，重新开始播放才会再次适配。结束后解除尺寸锁。纯脚本播放按实际客户区换算鼠标坐标，播放期间不截图；普通游戏任务继续使用原有识别流程，仅在播放前窗口发生变化时刷新截图。

通用播放在本次任务中固定绑定文件及哈希，后续循环发现文件或绑定改变会停止，重新开始后才读取新版本。手动停止、正常完成、工作进程正常退出均释放本次输入和尺寸锁。该功能当前只完成工作区与离线验证，游戏实测和本地升级需另行进行。

### 盒子与脚本倍速

自动刷关的入口点击按住时长统一为：任务选择 1 倍速时 100ms，已确认 2 倍速时 50ms，覆盖主线、指定关卡和悬赏入口。抬起后的等待、进关核验和重试流程保持原有设置；此调整用于缩短入口切帧期间的按压窗口，不保证消除所有点击失败。手动改变盒子倍速不会自动改变任务的入口时长。

脚本刷关任务和通用脚本播放提供“盒子与脚本倍速”：默认“1 倍（默认）”不发送倍速按键，也不增加核验截图；若此前手动开启了盒子倍速，请先手动恢复 1 倍。选择“2 倍”后，助手向已选造梦盒子发送数字行 2，确认中心提示“设置2倍速”后，才按 2 倍播放绑定录制；脚本内容和保存时长不变，动作间隔及末尾等待均减半。

使用前进入《造梦西游4》，关闭盒子“高帧率”，退出输入框，并用正常 1 倍速度录制脚本。功能面向单机关卡，不用于联机副本、答题或炼丹。脚本若包含数字行 1/2 操作，会拒绝开启 2 倍，避免录制再次改变倍率；小键盘数字不属于这组倍速键。任务运行期间不要手动切换盒子倍率，助手不会持续截图监测人工变更。

同一任务的连续轮次复用已确认的倍速，不逐轮切换。正常结束、失败、手动停止时尝试恢复 1 倍并确认后，才结束任务或继续队列；已核验的盒子重启完成后重新确认 2 倍。未确认开启时不播放，未确认恢复时停止后续队列并提示检查；必要时在盒子按数字行 1 恢复。强制终止进程、系统崩溃等情形无法保证恢复确认完成。

截图只用于每次倍速切换：预热一帧，再最多三帧识别中心局部提示；核验后释放截图控制器。切换时等待盒子提示消退约 2.2 秒，避免提示遮挡后续点击，此等待不加到每轮导航或回放中。导航路由、关卡识别和战斗监测间隔保持原有设置；进关按压为 1 倍 100 毫秒、2 倍 50 毫秒，不逐轮累计折半；原生倍速也不保证实际通关耗时恰好减半。已完成源码核对、内存原生 OCR、跨进程清理及前端无界面检查；真实游戏中已检查孤魂岭的 2 倍播放和停止后恢复，未覆盖所有盒子版本、任务及异常情况。

选中已保存脚本后点击工具栏“重命名…”，或打开脚本行的“⋯ → 重命名…”。名称、文件名及已绑定的全部任务会一起更新，默认脚本身份也会保留；取消不会修改文件，同名文件不会被覆盖。有未保存的编辑时先处理保存提示。直接在资源管理器改文件名不会同步脚本内的名称和绑定，请使用工作台入口。自定义 Pipeline 中手写的固定文件路径不属于任务绑定索引，仍需自行调整。

## 使用前端

下载完整客户端后，从根目录的 `MAA造梦西游4.exe` 启动。它直接打开 MFA 前端；`MFAAvalonia.exe` 可直接打开前端。若整包没有 `MAA造梦西游4.exe`，请重新下载完整包，不要把前端构建附件当作完整客户端。

仓库不包含 MFAAvalonia 客户端源码和二进制。新增页面以固定上游源码补丁与页面源文件维护，需构建后使用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build_frontend.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/preview_frontend.ps1 -Launch
```

需要 .NET 10 SDK 和本项目已安装的内嵌 Python。预览目录是 `dist/script-studio`，使用独立配置与脚本库。`-Demo` 可加入一份只供编辑练习的示例，它不是实际副本策略。

如需替换本机原前端，先关闭原前端，再运行 `tools/build_frontend.ps1 -Install`。安装前会备份文件。构建与恢复说明见 [前端说明](../../frontend/README.md)。

## 录制

1. 启动造梦盒子，进入希望录制的战斗起点。
2. 打开“脚本库与录制”，刷新并选择游戏窗口，设置倒计时。
3. 点击“开始录制”，切回游戏操作。当前任务必须已停止。
4. **F8** 暂停/继续，**F9** 停录，**F10** 停录并保存；**F12** 停录。倒计时中按 F9 可立即开始。
5. 停录后进入“时间轴编辑”，检查或调整操作。首次点击“保存”时输入名称；取消命名会保留草稿。

录得不好时，可点击 **“放弃本次录制”** 一键结束并丢弃当前内容，无需先停录、命名或确认。开始倒计时、录制、暂停和继续倒计时均可使用；停止后尚未保存的录制也可在时间轴上方放弃，包括对这份录制草稿的编辑。录制区默认单击放弃，勾选 **“双击放弃本次录制”** 后，该区的放弃按钮需要双击；选项仅在当前页面有效，不影响快捷键和时间轴上的放弃按钮。放弃后返回录制区，可立即重新录制；不会生成恢复草稿，且无法撤销。已保存的脚本和任务绑定保持原样，保存后的录制不再显示该操作。

录制仅在明确点击开始后安装监听，停止后卸载。失焦或鼠标拖出客户区会暂停，不会自动继续；回到游戏后按 F8。暂停和停止会在数据中补齐键鼠释放，不向游戏额外发送输入。录制过程中窗口关闭、身份或客户区尺寸改变时停止并保留内容，不自动调整窗口。

支持键盘长按、组合操作、左/右/中键及拖拽、滚轮和阶段标记。鼠标悬停不会持续记录。录制格式使用短边720坐标，窗口尺寸和布局仍应保持稳定。

## 编辑

双击脚本行或点击该行的“编辑”。时间轴页也能直接选择脚本：宽窗口显示左侧脚本库，窄窗口使用顶部下拉框。

- 点击时间块或操作列表，在右侧修改开始时间、持续时长、按键、鼠标坐标等，点击“应用更改”。修改只作用于所选操作。
- 在轨道空白处拖动框选多个操作；Ctrl/Shift+单击增减选择，Ctrl+A 全选，Esc 取消选择或取消正在进行的拖动。点击上方标尺只移动查看位置。
- 拖动任一选中块会整体移动所有选中操作，保留相对间隔、按住时长和鼠标轨迹；多选时不调整单个块的边缘。右侧“批量编辑”可输入正负秒数整体平移。方向键每次移动 10 毫秒，Shift+方向键每次 100 毫秒。
- **Ctrl+C / Ctrl+V**：复制选中的完整操作，以播放头为粘贴起点。跨行选择保留原按键和鼠标轨道、相对时间、按住时长及拖动轨迹；粘贴后选中全部新增块，Ctrl+Z 一次撤销。可跨脚本粘贴，同一按键或鼠标轨迹发生冲突时拒绝整次粘贴；含鼠标坐标的片段要求两份脚本尺寸相同。复制的结束标记作为普通标记，原脚本结束标记随总时长延伸。文本输入框继续使用自身的复制粘贴。
- 以播放头定位、保留多轨相对关系参考 [Premiere 的复制粘贴](https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-sequence/copy-and-paste-clips.html)与 [After Effects 的关键帧复制](https://helpx.adobe.com/after-effects/desktop/animate-in-after-effects/animation-keyframes/editing-moving-copying-keyframes.html)。本工具的轨道代表真实按键和鼠标类型，因此不会按鼠标悬停行改换按键，也不覆盖已有输入。
- 单选时拖动块的边缘改变时长；默认吸附 10 毫秒，Alt 切换为 1 毫秒。Ctrl+滚轮缩放，也可使用“适合窗口”。
- 右侧参数区可拖动分隔条调整宽度。“最大化时间轴”隐藏两侧面板和操作列表；“还原工作区”恢复。操作列表默认折叠，需要时展开。
- 常用按钮使用几何图标，悬停显示中文名称与快捷键。“更多”中提供脚本检查、修复未释放键鼠和轨道高度设置。
- “添加操作”可添加按键长按、鼠标点击、文本、移动、滚轮或标记。键鼠按下与释放成对处理。Ctrl+D 复制单个操作；Delete 或“删除选中操作”一次删除整个选区，按下与释放成对删除。每次整组移动或删除均可用 Ctrl+Z 一次撤销，Ctrl+Shift+Z 重做。
- “位置（秒）”只移动查看位置，不发送游戏输入。“分割脚本”要求切点处所有键鼠都已释放，并且前后都有动作；生成两个新文件，保留原脚本。
- Ctrl+S 保存当前文件；Ctrl+Shift+S 另存为独立文件。默认脚本也可以直接编辑和保存。
- 缩短或删除操作保留总时长；延长至末尾外才增加时长。拖拽修改会同时调整轨迹，多按钮共享轨迹必须把所有关联操作一起选中，避免修改一部分后留下孤立按键。
- 编辑“总时长（秒）”后，可点击“应用时长”，也可直接保存或导出；保存会先提交尚未应用的时长。修改支持撤销、重做。橙色结束线表示实际回放结束时间，红色线表示查看位置。“录制停止／结束录制”标记及同刻的末尾暂停标记跟随脚本终点；拖动结束标记也会修改总时长。总时长不能早于最后一个真实动作或普通阶段标记，避免静默截断按键。旧文件中落在旧时间的停止标记会对齐当前总时长，原时间保留在标记元数据中。
- 参数尚未应用、脚本尚未保存时，切换和关闭会提示处理。保存失败或文件被外部修改时保留草稿，不覆盖外部版本。
- 撤销重做共保留最多100个状态，并受历史内存预算限制；较大录制可保留的历史更少。

旧录制的孤立释放、缺失释放和未知动作会显示诊断。“修复未释放键鼠”只修复缺少的释放；其它问题需要编辑或删除对应操作。未知字段在导入编辑中保留。

## 脚本库与默认录制

客户端仅随附一份格式示例，首次打开时进入脚本库并标注“默认脚本”。它与用户脚本使用相同的编辑、保存、导出和绑定操作；格式示例不是真实战斗策略，也不会自动绑定任务。请为需要回放的任务录制或导入合适的脚本并绑定。旧版已存入用户脚本库的录制和绑定不会因移除随包模板而删除。

“新建”先建立未命名草稿，保存时再命名；“导入…”支持原工程格式和本工程格式。每行的“⋯”包含“复制脚本…”“导出…”和“删除…”，工具栏也可删除当前脚本。删除会同时解除该文件的任务绑定，并把文件移入 `recordings/.trash` 以便恢复。

默认脚本只初始化一次。编辑后的文件不会被更新覆盖，删除后也不会在下次启动时恢复。复制或另存为的文件是独立用户脚本，不继承任务绑定。小窗口下录制区折叠在列表上方，展开后可开始录制。

## 用于任务回放

点击脚本所在行的“绑定任务…”（已绑定时显示任务名称或数量），勾选一个或多个任务并确定。取消勾选可解除绑定；一个任务同时使用一份脚本，选择已绑定其他文件的任务时会提示将替换的文件。自定义实例任务和导入的任务定义也会列出。

- **关卡任务**：保留导航、识别和退出流程，只替换 `battle_play` 节点使用的脚本。
- **其他任务（仅执行脚本）**：跳过原任务流程，仅回放绑定脚本。必须先进入脚本所需的起始场景；不会自动补充副本导航或自动恢复。

脚本来源统一由任务绑定决定，不再提供“最新录制”“脚本工具当前选择”等来源选项。保存同一文件后，下轮使用新版；另存文件需重新绑定。需要战斗脚本的任务在未绑定或文件失效时会停止并提示，不擅自使用其他脚本。任务重命名或更换入口后需重新绑定。绑定应用到使用相同任务名称及入口的实例，仍由 MFA 控制重复次数与执行顺序。

刷取次数可设正整数或 `-1`。`-1` 持续刷取直到手动停止；遇到未知场景或不可恢复错误仍会停止。“任务失败后自动重试”默认关闭；启用后每轮重试上限可设 `0–20`，`0` 表示不自动重开，正数为最多额外重试次数。只对已识别的挑战失败执行返回地图、确认并重新进入同一任务，未知场景不重试。

倒计时会显示实际剩余秒数。失焦暂停后，单击“继续（3秒准备）”即可进入3秒倒计时，在结束前切回游戏；未切回则保持暂停并提示。可取消继续，也可在游戏中按 F8 立即继续。倒计时和暂停均不计入录制时长，初始倒计时可取消并保留当前脚本。

在任务设置中回答“录制内容是否包含返回地图”：选择“是”时由录制完成返回，任务检查返回画面；选择“否”时由任务执行退关。普通关卡任务默认“否”，守卫宝烛沿用完整录制默认“是”。自定义任务如需完整返回录制，应在回放节点声明 `script_binding.recorded_return_next` 返回确认入口；缺少该入口会提示而不会盲目跳转。

源工程的带坐标滚轮与当前后台输入语义不同：可以导入、查看和编辑，但真实回放会明确拒绝这类动作；普通旧版滚轮继续按原方式执行。

## 通用导航与战斗失败

现有 11 个脚本任务共用导航与结算识别。先尝试当前目标和当前任务的相关界面，未命中时才关闭已知覆盖层或通过世界地图、南瞻部洲中转；普通关卡需要跨洲时使用本任务对应的已标定世界入口。点击后核验结果，每次使用新识别的位置，不使用最短路径规划或每轮全库扫描。

悬赏任务先确认具体名称、已接受状态和“前往副本”，不会通过须弥山悬赏榜接取或进入。普通关卡支持已确认地图上的有界视野恢复：孤魂岭向右、万世冥阁向左、金蟾宝宫向上拖动；每次拖动前重新核对地图、普通模式与安全地形。没有可靠入口的画面仍会停止，不猜坐标。

“任务失败后自动重试”默认关闭。识别到“挑战失败”后，立即停止后续回放并释放已按下的键鼠，再点击该失败页的“返回地图”，确认返回后结束本轮，失败不计入完成次数。启用后，在同一轮内重新导航、进入并回放；每轮默认最多重试 3 次，可设为 1～20 次，用尽后停止。失败重试不会再次经过刷取计数入口；成功返回后才进入下一轮。人工停止、截图失败、未知页面、验证码和脚本损坏不按死亡重试。

“挑战成功”页使用独立的返回按钮识别，按钮必须与成功标题同时出现。任务开始时若已经停在成功或失败结算页，先返回地图，再开始本次请求的轮次，历史结算不计入本次次数。没有出现结算页时，仍按“录制内容是否包含返回地图”执行原有退出方式；用于刷经验的主动退关仍有效，不额外要求悬赏达到 1/1。

当前轮及失败重试固定同一脚本文件和修订哈希，中途改写会停止；下一轮才读取重新保存的版本。公共导航与素材已经随 `agent/` 和 `resource/` 分发，运行不需要旧工程、旧 Qt 环境或 Pillow。源码同步时使用现有任务同步工具，它会一并复制动态导航依赖；不要只复制某个任务 JSON。

迁移范围、尚缺校准的路径及离线验证见[通用导航迁移与失败重试说明](通用导航迁移与失败重试说明.md)。

## 四个悬赏脚本入口

守卫宝烛、守卫太宗、追捕飞贼、遁地大盗分别保留脚本绑定，共用一套进关、回放、返回与重试流程。宝烛不再单独维护任务或登录恢复链；四个入口均使用当前实例的游戏管理。

1. 先手动接取与所选任务对应的悬赏，建议停在主线地图、任务面板或已接悬赏详情。流程沿“任务 → 悬赏任务页签 → 对应悬赏详情 → 前往副本”，同时核对名称、已接受状态、按钮及遮挡。主线页也有“已接受”和“前往副本”，这两个条件不能单独作为悬赏入口。不会自动接取、付费重试或新建角色。
2. 在所需脚本行点击“绑定任务…”，勾选对应悬赏入口并确定。四个入口分别保存绑定；新安装需先保存自己的录制并绑定，升级保留已有绑定。
3. 根据录制内容将“录制内容是否包含返回地图”设为“是”或“否”。完整返回录制不会再次执行退出；仅战斗录制由 Pipeline 打开设置并返回地图。
4. 用前端设置完成轮数或挂机。进关后复用无双按钮及已有遮挡处理，场内就绪才回放，返回地图后计次。未接悬赏、未知页面或验证码不会猜测点击；终止失败是否重启由游戏管理单独决定。

录制应从进入副本后的战斗画面开始。旧录制若含世界地图、须弥山或悬赏榜的进关动作，须先在时间轴裁剪这些动作或重新录制；更新不会替你改写个人脚本。

任务绑定保存在 `recordings/.bindings.json`，只记录库内文件名。编辑保存仍写同一文件，下一轮会读取新版；当前轮及其恢复重试固定首次准备时的文件版本，中途外部改写会停止该轮。另存为新文件不会自动改绑，请再次点击绑定。使用短边720的录制与相同游戏布局；原尺寸数据须先通过导入转换，不能仅修改 `base` 数字。

### 游戏管理与自动恢复

任务页的“游戏管理”统一配置失败、内存和间隔分钟重启，默认关闭；原任务说明移到“任务设置”的“使用说明”折叠区。填写所选造梦盒子 EXE、历史账号名称、已有存档槽位 1～8 和角色名，先保存连接信息，再启用重启条件。旧任务内“自动恢复”选项退役，旧数据保留在迁移备份中，不自动开启新开关。

任务设置只保留一处“完成轮数”。“挂机模式”统一表示无限刷取和无限游戏内战败重试；灰色的轮数与重试值是退出挂机后使用的设置。旧版 `-1` 无限次数会迁移为挂机模式。普通模式可以关闭重试，或设置每轮 1～20 次游戏内重试。

游戏内重试优先于盒子重启。只有重试耗尽、返回流程无法恢复、白屏或目标窗口丢失等允许恢复的故障，才按“游戏管理”的失败重启开关恢复原轮；单纯开启挂机不会开启重启。盒子同一轮连续恢复最多 3 次，恢复后仍失败会停止并提示。内存与定时重启等待本轮成功返回地图；已经完成的轮数保留。前端先停止旧输入及 Agent，再核验进程、重启、重连并确认账号、存档和地图。其它实例共用进程、窗口不唯一、角色不符、验证码、未知页面、脚本变化或取消均停止。答题任务只在确认整局结束后维护，异常中断保留日志并停止，绝不重新开局。设置、日志位置及验收范围见[游戏管理](游戏管理.md)。

框架按用户选择的控制器发送输入，不强制使用旧工程的前台 Seize 模式。后台按键与具体游戏客户端是否兼容、真实进出关及重启效果仍需在用户环境验收；开发测试使用静态截图、内存控制器和模拟生命周期，不会重启用户游戏。

AIR 后台导航与回放新增操作期间的鼠标离开保护：过滤已绑定游戏窗口的额外离开通知，避免孤魂岭按下、抬起命中不同子对象。无需把真实鼠标停在关卡上，也不抢焦点；完成、停止或异常后解除。请同步完整 Agent 与 `MaaBackgroundMouseGuard.dll`，缺少模块会在输入前报错。原因、边界与回滚见[后台点击与孤魂岭事件修复](后台点击与孤魂岭事件修复.md)。真实游戏效果需复测，任务运行期间不要同时在游戏窗口内手动操作。

源码用户更新时先关闭前端，运行 `python tools/sync_task_assets.py --apply --update-version` 同步全部任务，再用 `tools/build_frontend.ps1 -Install` 安装前端。同步工具默认只预览，应用时备份相关文件，保留控制器、OCR、个人录制、任务绑定和重复次数；按迁移清单清除旧录制入口与无引用的来源选项。`--task <任务名>` 仍支持单任务更新，但不会执行全局入口清理。新任务初始重复次数为1，恢复默认关闭。

## 手动升级客户端

自 2.4.2 起使用完整客户端手动安装，旧资源更新器和通用 MFA 自动更新保持禁用。先在“版本与手动升级”导出个人配置 ZIP，再停止任务并退出助手。使用完整安装包时，已确认的旧客户端目录会原位保留个人配置、录制、绑定及布局并替换旧程序；普通或无法确认的目录会自动追加 `MAAZMXY4` 子目录。安装器不备份旧程序，也不自动启动助手。安装到新位置后，可通过同一页面导入个人 ZIP。

以下仅供使用完整 ZIP 手动覆盖的用户；EXE 安装器已内置相应迁移，不需要再执行一遍：

1. 停止任务并退出旧助手，完整备份旧客户端目录。将新版完整客户端解压到另一个目录，先不要覆盖旧 `interface.json`，迁移旧“回放文件”选择需要读取它。
2. 在新版客户端目录打开 PowerShell，执行以下命令（把目标路径改成旧客户端目录）。首次不带 `--apply` 查看迁移计划，确认目标目录后再应用。

   ```powershell
   .\runtimes\python\python.exe .\agent\task_asset_sync.py --target "D:\旧客户端" --update-version
   .\runtimes\python\python.exe .\agent\task_asset_sync.py --target "D:\旧客户端" --update-version --apply
   ```

3. **迁移成功后**，将新版的 `MAA造梦西游4.exe`、前端程序、`libs/`、完整运行依赖、`agent/`、`DependencySetup_依赖库安装_win.bat`、构建记录与许可文件覆盖到旧目录。保留迁移后的 `interface.json`、`config/`、`recordings/`、`appsettings.json` 及已有布局，不要用安装包里的配置覆盖它们；`agent/recordings/` 的已有文件也应保留。项目版本已由迁移工具更新；原目录的 `backup/task-assets-*` 保存迁移前文件。跨大版本优先使用 EXE 或新目录安装，避免 ZIP 覆盖残留退役程序。
4. 从旧目录中已更新的 `MAA造梦西游4.exe` 启动，确认能进入新版前端、脚本及任务绑定仍在，再用一轮任务验证。此前未选择明确文件或没有旧录制的任务，需要在脚本库中首次绑定。

迁移会把旧“回放文件”的明确选择转成新绑定，已有绑定优先；“最新录制”固定为迁移时已有的最新文件，避免默认模板入库后改变选择。必须在覆盖旧 `interface.json` 前运行迁移；只保留录制文件和配置、直接覆盖任务定义，仍可能丢失旧选择的含义。若多个配置为同一任务选择不同文件，或明确选择的文件已不存在，工具在写入前报错，请先解决冲突；不要忽略错误继续覆盖旧目录。

任务标识 `task-…` 由任务名称与入口计算，不包含电脑 ID。绑定内容只保存在用户的 `recordings/.bindings.json`，不会随公共包发布。

## 批量导入旧录制

批量导入工具只读取 ZaoMengScript 的 `data/scripts/*.json`，调用本工程的录制模型转换格式。它不读取任务队列、不导入原工程 Python 代码，也不依赖原 Qt 界面、OCR 模型或运行环境。只需保留原格式录制及其 `data/scripts` 目录结构。

```powershell
# 预检录制；去掉 --dry-run 后写入当前工程脚本库。
python tools/migrate_zaomeng_scripts.py --source ../ZaoMengScript --target . --dry-run
python tools/migrate_zaomeng_scripts.py --source ../ZaoMengScript --target .
```

录制保存在 `recordings/`，可在“脚本库与录制”刷新查看、进入时间轴编辑。导入以源 ID 和文件哈希识别版本，重复执行复用已有文件；已编辑的目标录制保留，新源版本另存。导入不会设置全局任务回放文件。

导入清单位于 `.local-migrations/zaomeng/scripts.json`，与个人录制一起由 Git 忽略。导入后的编辑和回放使用本工程的录制格式、脚本库及回放引擎。该工具只转换录制数据，不创建任务或替换任务流程。

### 后台鼠标保护清理

鼠标保护结束时会等待目标线程确认已处理队列，确认到达即继续；进关加载暂时占用线程时最多等待 5 秒，不增加截图或固定延时。若仍无法确认清理，停止本次任务并报告鼠标保护错误，不交给游戏管理反复重启盒子；挂机、普通刷关和通用脚本播放均不把此错误计为成功。窗口丢失等原有恢复条件仍沿用原策略。
