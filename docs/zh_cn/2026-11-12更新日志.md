# v2.5.1 候选更新说明

以已发布的 v2.5.0 为基线，当前处于 PR 与 Release 准备阶段。源码版本和本地候选包不代表正式发布；正式资产以项目 Release 页面为准。

## 识别与输入修复

- **复活弹窗**：识别固定的复活标题和布局，再点击对应的取消位置；不再把取消文字、免费次数、剩余还魂丹数量或变化的倒计时作为必要条件。未知浮窗先释放输入，再有限重判，仍不能识别则停止；诊断保存当次判定帧，不额外截图。
- **前两洲入口**：南瞻部洲与东胜神洲不再要求普通/噩梦切换按钮；其它洲沿用适用的模式条件。
- **通用进关确认**：62 个主线、7 个 Boss 和4 个悬赏入口复用同一套无双按钮识别，兼容未蓄满与已就绪状态；进关后不再核对关卡名称、背景或独立地标。地图入口定位、已知遮挡处理、返回确认和计次继续使用现有流程。
- **后台鼠标 DPI**：通用脚本发送鼠标消息时，复用物理像素线程上下文并在结束时恢复，修正 125% 等系统缩放下的落点偏移。
- **暗色弹窗**：脚本保存、另存为、复制、重命名及删除确认复用 MFAAvalonia/SukiUI 的动态背景和文字资源，随主题切换；继续使用原有名称校验与保存、取消流程。

## Boss 行为资料

游戏百科为诛仙剑、戮仙剑、陷仙剑、绝仙剑和巨水灵增加可展开的简明行为树，介绍行为分支、出招条件及已确认的时序。每条资料标注适用变体、版本、证据位置与摘要。

资料来自 2026-10-19 配置和标明版本的单机代码历史快照，仅适用于列出的普通主线变体。选招距离不是精确攻击判定范围；尚未分析完整逐帧判定区域，也未完成这些行为的实战复核。当前使用可展开逻辑树，方框、菱形流程图的重新设计不在本版范围内。

## 验证范围

- 2026-11-12 在本地造梦盒子中实测：暗色“另存为”和删除确认、浅色“另存为”显示正常，取消后原脚本保留。
- 抱犊山、桃花谷分别完成进关、无双识别、已有脚本回放、返回地图和 1/1 轮确认；桃花谷覆盖世界地图到东胜神洲的导航。
- 幻境阁成功进关、命中无双识别并开始播放已有录制；因达到既有内存/定时重启条件提示，测试主动停止，没有验证完整一轮，也没有触发重启。一次任务启动截图耗时约 1.58 秒，不能据此宣称截图延迟已全部解决。
- 复活弹窗没有在这次实机测试中自然出现；其变化计数和倒计时仅有离线、Maa 内存控制器及相关通信回归证据，仍需更多实机覆盖。
- 通用脚本 DPI 修复有线程上下文、消息失败恢复及坐标回归；不同显示器/DPI 组合没有逐项实测。
- 新候选包仍需完成包内依赖、安装与正式发布资产验收。停止回放时，控制器提前结束可能导致释放输入未确认的旧限制仍见 [v2.5.0 说明](2026-11-07更新日志.md#验证与已知限制)。

## 升级

继续使用完整 EXE/ZIP 手动升级；安装前退出小助手并导出个人配置 ZIP。保留已有任务标识、选项、录制和绑定，不恢复应用内自动更新。新行为资料不包含单机游戏原始代码或完整资源包。
