# 游戏管理

任务页原“任务说明”卡片改为“游戏管理”；任务说明移到“任务设置”内的折叠区，随选中任务更新。管理提示、错误和维护结果统一写入现有日志。首次进入 MFA 的引导暂时关闭，已有布局和用户设置不重置。

## 配置与操作

当前适配造梦盒子 **1.9**（AIR 应用 `dusk.zmBox`）。在连接设置中明确选择目标窗口，在游戏管理填写或选取现有盒子 EXE，填写盒子历史账号列表中的名称、已有存档的角色名及槽位 1～4，然后保存到当前实例。恢复利用盒子已经保存的账号；助手不读取密码、令牌或账号缓存，不自动新建角色。

“启动并连接”可以启动所选盒子，或连接明确选中的已运行窗口。已有同路径进程但未选择窗口时会提示先选择，不另开副本。登录后核对账号、角色和地图；验证码、登录错误、角色不符、空存档和未知画面均停止。连接一个已经进入地图的窗口时，视为用户已明确选择当前会话；之后的重启仍须重新核对历史账号和角色。

三个开关默认关闭：

| 选项 | 触发及执行方式 |
| --- | --- |
| 任务失败后自动重启 | 当前 11 个刷关及悬赏脚本任务中，对已确认挑战失败、白屏或已核验窗口丢失恢复同一轮，每轮最多 3 次；失败不计为完成。 |
| 内存超过 1.8 GB 自动重启 | 每 5 秒读取目标进程专用内存，连续两次超过 1,800,000,000 字节后安排维护；十分钟内三次内存重启后仍超限则停止自动托管。 |
| 定时自动重启 | 每隔指定分钟安排维护，支持 1～10080 分钟；成功重启后重新计时，默认 60 分钟。 |

内存与定时维护在当前轮成功返回地图后执行，保留已完成次数；空闲托管会话可以直接维护。“重启”在托管任务中也安排到本轮结束，空闲时立即执行。“关闭”只操作已核验的所选进程，任务运行时须先停止。手动停止或恢复失败会解除本次自动监测；重新保存设置或主动启动、重新运行任务才能继续。

生存大冒险自动答题只在**确认整局结算后**执行待处理重启。异常中断、窗口丢失、未确认结算或连续 180 秒未取得答题进展时，保留日志并停止，不重启、不重新开局。该任务不使用“任务失败后自动重启”重试当局，以免消耗每日次数。

## 续跑和识别范围

任务继续使用原 Maa 队列、控制器、回放、绑定及任务计次规则。托管将可确认的单轮交给现有恢复机制；重连前停止旧输入和 Agent，核对进程路径、启动时间、唯一窗口及原客户区尺寸，确认恢复后才重试。相同进程被另一个运行或托管实例占用时拒绝接管。替代整个任务的自定义录制没有可靠结算边界，开启托管时会停止并说明原因。

当前游戏会恢复存档所在洲；重新加载地图从初始位置开始，普通刷关期间则可能保留拖动位置。地图视野恢复属于通用导航，不依赖游戏管理开关：孤魂岭向右拖动地图寻找左侧目标，万世冥阁向左拖动寻找右侧目标，各最多 3 次；金蟾宝宫沿用向上拖动，最多 12 次。只有任务按钮、普通模式和非交互地形同时匹配且没有复活提示时才允许拖动；未知地图和模式不尝试。

旧版 `4061dcc` 的关卡入口采用全图 TemplateMatch，并点击本次匹配框，未实现自动寻找画面外关卡。新版保留这种动态定位：血海图标的普通、可进入和悬停素材都搜索整帧，地图移动后重新识别，后续原生入口再次匹配才点击。拖动起点来自当前帧的安全地形，终点使用相对偏移；不保存旧坐标，也不恢复旧版固定“点击场外”的失败兜底。普通模式首先匹配原按钮模板，备用判断只识别右下角完整的“切至噩梦”文字，不点击模式按钮。

旧守卫宝烛的任务内“自动恢复”选项退出界面，由当前实例的游戏管理开关统一控制；旧配置由任务迁移备份保留，不会自动启用新开关。任务标识、录制、绑定、勾选和重复次数沿用原值。原来的“失败自动重试”仍表示不重启盒子的同轮重试；同时启用失败重启时，仍优先在游戏内重试，耗尽或返回流程无法恢复后才重启；挂机不受游戏内重试次数上限影响，盒子恢复仍独立限制为每轮 3 次。

诊断写入助手数据目录的 `debug/task-runs/` 和 `debug/game-management/`，记录轮次、状态和录制修订，不保存密码。托管运行期间固定绑定的录制修订；修改录制会停止，需重新开始任务。

## 开发验证与待验收范围

实现通过固定 MFA 源码覆盖层及补丁构建，资源由现有同步、打包工具收集。离线覆盖策略和计次、实例隔离、原生控件布局、真实 Maa/Agent 通信、合成登录与存档画面、当前 SWF 地图拖动及错误目标拦截。所有原生检查使用内存控制器，不连接真实窗口。

源码构建和离线检查不代表真实登录或关卡已通过。2026-10-29 本次血海兼容修订只完成源码、生成资源和替身逻辑检查；新增反向拖动及文字模式判断的原生图像识别与实机验收均未执行，按用户要求暂时跳过血海验证。实机仍需在获得当前范围授权后核对盒子字体、DPI、账号列表、存档、重启重连、刷关与悬赏续跑、答题结算及异常停止。当前未安装到日常客户端，未发布正式安装包。

构建保留固定上游的依赖版本，仍输出既有的 NuGet 依赖告警与弃用 API 警告；本功能未升级这些依赖。不能将本次编译通过理解为依赖安全审计通过。

来源记录见 `agent/data/navigation/game-management.json` 与 `stage-scroll.json`。盒子登录布局参考 [duskeye/zmBox 的固定源码](https://gitee.com/duskeye/zmBox/tree/05e4975f61c5fe137552bd06ca97ee3cfa80279b)；游戏区域恢复和拖动规则来自当前公开 v5870 SWF，保留反编译文件及素材摘要。

设置页按“连接与存档 → 重启与续跑 → 手动操作”排列。重启开关即时保存，只更新开关，不顺带保存账号或角色草稿；无效草稿也不妨碍关闭重启。连接信息点击“保存设置”，定时分钟点击“应用间隔”。
