# v2.4.5 更新日志

本版包含 [PR #7](https://github.com/Inkyu-Zero/MAAZMXY4/pull/7) 的共享导航、脚本工作台及安装流程改进。

- **导航更轻量**：采用目标优先、相关候选和公共中转流程，同一次决策复用截图与识别结果，移除最短路径规划和重复节点。
- **血海循环更顺畅**：入口缺失时一次拖到对应端点，后续复用视野；进关点击未响应时，根据新截图快速重试，不再等满加载超时。
- **脚本与窗口匹配**：打开、录制和播放共用尺寸校验；录制、回放期间锁定窗口尺寸。新增通用脚本播放任务，可按次数或持续循环，不截图、不识别、不自动重启。
- **放弃并重录**：录制区四个按钮等宽分两排，放弃按钮标红，可选双击放弃；丢弃后直接重新开始，已保存脚本和绑定不变。
- **恢复与鼠标处理**：完善失败交接、窗口身份核验及重启续跑；鼠标操作后后台移开悬停，脚本仅在结束时移动一次，不额外增加等待。
- **完整离线安装器**：EXE 自带 .NET 和 VC++ 运行库安装程序；普通目录自动追加子目录，已确认的旧版目录保留个人配置、录制和布局后替换程序。继续提供完整 ZIP 和内置个人配置 ZIP 迁移。
- **依赖与回归**：核验包内 OpenCV、NumPy、Pillow 及炼丹的 11 张模板；CI 增加任务资源重生成、血海端点与真实 Agent 通信回归。

升级前请先导出个人配置 ZIP。新 EXE 安装器不备份旧程序，安装后不会自动启动助手；ZIP 手动升级步骤见[脚本工具说明](脚本工具-使用说明.md#手动升级客户端)。

使用者已确认测试版手动测试完成。自动验证采用离线图片、内存控制器和隔离环境，不代表所有旧版盒子、角色及 DPI 组合均已逐项实测。完整包文件与 SHA-256 以本版 Release 附件为准。
